# 0004: Content saved with the oldest supported engine

Status: Accepted, 2026-11-02
Evidence: [AdamskAIWorld.Content], [AdamskAIWorld.Map], [AdamskAIWorld.Demo.Content], [docs/dev/testing.md]
Commits: e1d0955

## Context

The plugin supports UE 5.6 to 5.8 from one source. An Unreal package reads in its own engine and newer ones, never
in an older one, so a test map or EQS asset saved with 5.8 makes the 5.6 and 5.7 test runs fail to load it.

## Decision

Everything in `Content/` (the test map, the EQS assets, the demo arena) is generated by code and saved with the oldest
supported engine, 5.6: `ADSK_GENERATE_WORLD_MAP=1` with `AdamskAIWorld.Content`, `ADSK_GENERATE_DEMO_MAP=1` with
`AdamskAIWorld.Demo.Content` ([testing.md](../testing.md#world-tests-adamskaiworld)). Nobody edits these assets in the
editor.

## Rejected

- One content set per engine: three copies of every binary asset to keep in step.
- Other alternatives: not recorded.

## Consequences

- Regenerating content needs a 5.6 install. A change made with 5.8 and saved is a regression, even when every 5.8
  test passes.
- Raising the oldest supported engine is a new decision: regenerate with it and supersede this one.
